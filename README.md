# TopFilm.uz — Termux versiyasi

Bu versiya Android/Termux uchun moslashtirilgan: `better-sqlite3` olib tashlangan va ma'lumotlar `data/topfilm.json` faylida saqlanadi.

## Ishga tushirish
1. `npm install`
2. `.env.example` faylidan `.env` nusxa yarating.
3. `.env` ichida kuchli `JWT_SECRET` (32+ belgi) va `ADMIN_PASSWORD` (12+ belgi) belgilang.
4. `npm start`
5. Brauzerda http://localhost:3000 oching.

Faqat tarqatish huquqiga ega bo‘lgan video va rasmlarni joylang.
